ინტერნეტი, HTTP და Front-end დეველოპერის პროფესია

სანამ ერთ ხაზ კოდსაც კი დავწერთ, უნდა გავიგოთ, რა ხდება მაშინ, როცა ბრაუზერში ვწერთ მისამართს და ვაწვებით Enter-ს. ეს გაკვეთილი გვაძლევს იმ საფუძველს, რომელზეც აშენდება მთელი კურსი.

1. რა არის ინტერნეტი და როგორ მუშაობს ვები

ინტერნეტი არის მილიონობით ერთმანეთთან დაკავშირებული კომპიუტერის გლობალური ქსელი, რომლებიც ერთმანეთს „ესაუბრებიან" საერთო წესების — პროტოკოლების — მეშვეობით. ვები (World Wide Web) კი ამ ინტერნეტის ზემოთ აშენებული სისტემაა, რომელიც საშუალებას გვაძლევს ბრაუზერით ვნახოთ დოკუმენტები, სურათები, ვიდეო და ინტერაქტიული აპლიკაციები.

ვების საფუძველია Client-Server მოდელი:

  • Client (კლიენტი) — ეს არის შენი ბრაუზერი (Chrome, Firefox, Safari), რომელიც ითხოვს ინფორმაციას.
  • Server (სერვერი) — დისტანციური კომპიუტერი, რომელიც ინახავს საიტის ფაილებს და პასუხობს კლიენტის მოთხოვნას.

HTTP — კლიენტისა და სერვერის „საერთო ენა"

როცა ბრაუზერში აკრეფ მისამართს, ბრაუზერი უგზავნის სერვერს HTTP მოთხოვნას (request). სერვერი ამუშავებს მოთხოვნას და აბრუნებს პასუხს (response) — HTML დოკუმენტს, სურათს ან სხვა რესურსს. HTTPS იგივე პროტოკოლის დაშიფრული, უსაფრთხო ვერსიაა.

2. რა არის Front-End Development

ვებ დეველოპმენტი პირობითად იყოფა ორ დიდ მიმართულებად:

  • Front-End — ყველაფერი, რასაც მომხმარებელი ხედავს და პირდაპირ ურთიერთქმედებს ბრაუზერში: სტრუქტურა, დიზაინი, ანიმაციები, ინტერაქტივობა.
  • Back-End — სერვერის მხარე: მონაცემთა ბაზები, ბიზნეს-ლოგიკა, API-ები, რომლებიც Front-End-ს „კვებავენ" მონაცემებით.

Front-End დეველოპერი მუშაობს სამი ძირითადი ტექნოლოგიით, რომელთაგან თითოეულს თავისი, მკაფიოდ განსაზღვრული როლი აქვს:

  • HTML — გვერდის სტრუქტურა და შინაარსი (რა არის გვერდზე).
  • CSS — გვერდის გარეგნობა (როგორ გამოიყურება).
  • JavaScript — გვერდის ქცევა და ინტერაქტივობა (როგორ რეაგირებს მოქმედებებზე).

ეს დაყოფა კარგად ჩანს ერთ მარტივ მაგალითში — სამივე ტექნოლოგია ერთ ფაილშია, მხოლოდ საილუსტრაციოდ:

<!DOCTYPE html>
<html lang="ka">
<head>
  <style>             /* CSS — გარეგნობა */
    button { background: #146B5C; color: white; }
  </style>
</head>
<body>
  <button id="greet">დაწკაპუნება</button>  <!-- HTML — სტრუქტურა -->

  <script>               // JavaScript — ქცევა
    document.getElementById("greet")
      .addEventListener("click", () => alert("გამარჯობა!"));
  </script>
</body>
</html>

3. დეველოპერული გარემო: კოდის ედიტორი

კურსის განმავლობაში გამოვიყენებთ Visual Studio Code-ს (VS Code) — უფასო, ღია კოდის ედიტორს, რომელიც დღეს ინდუსტრიის სტანდარტია. მისი მთავარი უპირატესობებია:

  • ჩაშენებული ტერმინალი და Git-ინტეგრაცია;
  • გაფართოებების (Extensions) ეკოსისტემა — მაგ. Live Server, რომელიც ცოცხლად ამოწმებს ცვლილებებს ბრაუზერში;
  • ავტომატური ფორმატირება (Prettier) და Syntax Highlighting.

ინსტალაციის შემდეგ, ჩვენს პროექტს ექნება მარტივი, მაგრამ მოწესრიგებული სტრუქტურა — ზუსტად ისეთი, როგორსაც ამ კურსშივე ვაწყობთ:

4. ბრაუზერის დეველოპერული ხელსაწყოები (DevTools)

ყველა თანამედროვე ბრაუზერს აქვს ჩაშენებული DevTools — ინსტრუმენტების ნაკრები, რომელიც დეველოპერს აძლევს საშუალებას საცოცხლედ დაინახოს და გამართოს გვერდი. იხსნება კლავიშით F12 (ან Cmd + Option + I — macOS-ზე). ყველაზე ხშირად გამოსაყენებელი ტაბებია:

  • Elements — HTML-ის სტრუქტურის და CSS-სტილების ცოცხლად დათვალიერება/რედაქტირება.
  • Console — JavaScript-ის კოდის გაშვება, შეცდომების და console.log()-ის შედეგების ნახვა.
  • Network — ყველა HTTP მოთხოვნის (request/response) მონიტორინგი — ზუსტად ის, რასაც ზემოთ ვისწავლეთ.

პრაქტიკული დავალებები

  1. დააინსტალირე VS Code და დაამატე Live Server გაფართოება.
  2. შექმენი ცარიელი index.html ფაილი სწორი <!DOCTYPE html>, <head> და <body> სტრუქტურით და გახსენი ის Live Server-ის მეშვეობით.
  3. გახსენი ბრაუზერის DevTools (F12), გადადი Console ტაბზე და გაუშვი ბრძანება console.log("გამარჯობა, ვები!").
  4. DevTools-ის Network ტაბში გახსენი ნებისმიერი საიტი და იპოვე ერთი მოთხოვნა, რომლის სტატუს კოდიც 200-ია. ჩამწერე, რომელი ფაილი ჩაიტვირთა.
  5. (რთული) საკუთარი სიტყვებით, 5–6 წინადადებით აღწერე, რა ხდება იმ მომენტიდან, როცა ბრაუზერში აკრეფ საიტის მისამართს, მანამ, სანამ გვერდი ეკრანზე გამოჩნდება.
