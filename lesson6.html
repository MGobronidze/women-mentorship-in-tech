CSS Flexbox და პოზიციონირება

Flexbox არის ის ინსტრუმენტი, რომელიც საბოლოოდ წყვეტს „როგორ დავალაგო ელემენტები ერთმანეთის გვერდით" პრობლემას. ამას ვამატებთ პოზიციონირების სისტემასაც — ორივეს ერთად ხშირად ვიყენებთ.

1. Flexbox — საბაზისო კონცეფცია

Flexbox არის ცალგანზომილებიანი (ერთი ხაზის მიმართულებით — ჰორიზონტალურად ან ვერტიკალურად) განლაგების სისტემა. ის შედგება ორი მხრიდან: container (მშობელი ელემენტი, რომელსაც ვუწერთ display: flex) და items (მისი პირდაპირი შვილები). 

.container {
  display: flex;
}

როგორც კი მშობელს დავუწერთ display: flex-ს, ყველა მისი პირდაპირი შვილი ავტომატურად დალაგდება ერთ ხაზზე, გვერდიგვერდ.

2. Container-ის თვისებები

.container {
  display: flex;

  flex-direction: row;        /* row | row-reverse | column | column-reverse */
  flex-wrap: wrap;            /* nowrap | wrap — გადადის თუ არა შემდეგ ხაზზე */

  justify-content: space-between; /* განლაგება მთავარი ღერძის მიმართულებით */
  align-items: center;            /* განლაგება განივი ღერძის მიმართულებით */
}
  • flex-direction — განსაზღვრავს მთავარ ღერძს: row (ჰორიზონტალურად, ნაგულისხმევი) თუ column (ვერტიკალურად).
  • flex-wrap — nowrap (ნაგულისხმევი, ელემენტები „იჭყლიტება" ერთ ხაზზე) თუ wrap (გადადის ახალ ხაზზე, თუ ადგილი აღარ ჰყოფნის).
  • justify-content — მთავარი ღერძის მიმართულებით განლაგება: flex-start, center, flex-end, space-between, space-around.
  • align-items — განივი ღერძის მიმართულებით განლაგება: stretch (ნაგულისხმევი), center, flex-start, flex-end.

3. Items-ის თვისებები

ამ თვისებებს ვწერთ ცალკეულ item-ს, არა container-ს:

.item {
  order: 2;          /* ცვლის ვიზუალურ თანმიმდევრობას (ნაგულისხმევი: 0) */
  align-self: flex-end; /* ერთი კონკრეტული item-ის align-items-ის „გადაფარვა" */
}

order გამოსადეგია, როცა გვინდა ერთი კონკრეტული ელემენტი ვიზუალურად სხვა ადგილას გამოჩნდეს, HTML-ის თანმიმდევრობის შეცვლის გარეშე. align-self კი საშუალებას გვაძლევს ერთ item-ს ჰქონდეს container-ის align-items-გან განსხვავებული განლაგება.

პრაქტიკული მაგალითი: ნავიგაციის ზოლი

<nav class="navbar">
  <div class="logo">front-end-course</div>
  <ul class="links">
    <li><a href="#">მთავარი</a></li>
    <li><a href="#">სილაბუსი</a></li>
  </ul>
</nav>

/* CSS */
.navbar {
  display: flex;
  justify-content: space-between; /* ლოგო მარცხნივ, ბმულები მარჯვნივ */
  align-items: center;
}
.links {
  display: flex;
  gap: 24px; /* მანძილი ელემენტებს შორის, margin-ის გარეშე */
}

4. Positioned Elements

position თვისება განსაზღვრავს, როგორ „გაერევა" ელემენტი ჩვეულებრივ დინებაში (document flow) და გამოიყენება top/right/bottom/left-თან ერთად:

  • static — ნაგულისხმევი მნიშვნელობა; ელემენტი მისდევს ჩვეულებრივ დინებას, top/left და სხვ. არ მოქმედებს.
  • relative — ელემენტი „გადაინაცვლებს" საკუთარი, ნაგულისხმევი პოზიციიდან, მაგრამ ისევ იკავებს ორიგინალურ ადგილს დინებაში (სხვები „ხედავენ" მას, თითქოს არსად წასულა).
  • absolute — ელემენტი მთლიანად ამოვარდება დინებიდან და პოზიციონირდება უახლოესი relative (ან absolute/fixed) წინაპრის მიმართ.
  • fixed — პოზიციონირდება ბრაუზერის ფანჯრის მიმართ და „მიმაგრებულია" — არ მოძრაობს სქროლვისას.
  • sticky — ჰიბრიდი: იქცევა როგორც relative, სანამ არ მიაღწევს განსაზღვრულ ზღვარს (მაგ. top: 0), შემდეგ იქცევა როგორც fixed.
/* sticky ჰედერი — ზუსტად ისე, როგორც ამ საიტის ნავიგაციაშია გამოყენებული */
.site-header {
  position: sticky;
  top: 0;
  z-index: 50;
}

/* badge, რომელიც card-ის კუთხეში „ეკვრის" */
.card { position: relative; }
.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}

პრაქტიკული დავალებები

  1. შექმენი 3 ყუთი ერთ container-ში, დაუყენე display: flex და გამოსცადე justify-content-ის სხვადასხვა მნიშვნელობები.
  2. იგივე container-ს დაუყენე flex-direction: column და დააკვირდი, როგორ იცვლება განლაგება.
  3. ააწყვე ნავიგაციის ზოლი ლოგოთი მარცხნივ და ბმულებით მარჯვნივ, space-between-ის გამოყენებით.
  4. შექმენი card, რომელშიც ერთი „badge" ელემენტი position: absolute-ით მიმაგრებულია კუთხეში.
  5. (რთული) ააწყვე sticky ჰედერი, რომელიც სქროლვისას რჩება ეკრანის თავზე — შეამოწმე, რომ z-index სწორადაა დაყენებული და ის სხვა კონტენტს არ ეფარება.
