HTML სტრუქტურა, ტერმინები, ტექსტის ტეგები და ბმულები

ამ გაკვეთილში ავაწყობთ დოკუმენტის „ჩონჩხს", ვისწავლით HTML-ის ძირითად ლექსიკას, ტექსტის ტეგებს და ბმულებს — ვების ის „ძაფი", რომელიც გვერდებს ერთმანეთთან აკავშირებს.

1. HTML დოკუმენტის სტრუქტურა

HTML (HyperText Markup Language) მარკირების ენაა, რომელიც აღწერს დოკუმენტის შინაარსსა და სტრუქტურას ტეგების მეშვეობით. ყოველი HTML დოკუმენტი იწყება ერთი და იმავე საბაზისო ჩონჩხით: 

<!DOCTYPE html>                    <!-- ეუბნება ბრაუზერს: ეს HTML5-ია -->
<html lang="ka">                     <!-- დოკუმენტის ძირი, ენის მითითებით -->
<head>
  <meta charset="UTF-8">            <!-- სიმბოლოების კოდირება -->
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">  <!-- მობილურზე სწორი მასშტაბი -->
  <title>გვერდის სათაური</title>
</head>
<body>
  <!-- აქ ჩაწერილი ყველაფერი ჩანს ეკრანზე -->
</body>
</html>

<head> სექცია არ ჩანს გვერდზე — ის ატარებს მეტამონაცემებს. <body> კი შეიცავს ყველა ხილულ ელემენტს.

2. HTML ძირითადი ტერმინები

სანამ შემდეგ ტეგებზე გადავალთ, დავაზუსტოთ ლექსიკა, რომელსაც მთელი კურსის განმავლობაში ვიყენებთ:

  • ტეგი (tag) — კუთხოვან ფრჩხილებში ჩასმული ინსტრუქცია, მაგ. <p>.
  • ელემენტი (element) — გახსნის ტეგი + შემცველობა + დახურვის ტეგი ერთად: <p>ტექსტი</p>.
  • ატრიბუტი (attribute) — დამატებითი ინფორმაცია გახსნის ტეგში, ფორმით name="value", მაგ. lang="ka".
  • ჩადგმა (nesting) — ერთი ელემენტის მოთავსება მეორის შიგნით. ჩადგმულმა ტეგებმა უნდა დაიხურონ იმავე თანმიმდევრობით, რომლითაც გაიხსნენ.
  • Self-closing ტეგი — ტეგი, რომელსაც არ სჭირდება ცალკე დახურვა (არ აქვს შემცველობა), მაგ. <img>, <br>, <input>.
<!-- სწორი ჩადგმა -->
<div>
  <p>ტექსტი <strong>მნიშვნელოვანი</strong> ნაწილით.</p>
</div>

<!-- არასწორი ჩადგმა — ტეგები გადაჯვარედინებულია -->
<p><strong>ტექსტი</p></strong>

3. სათაურები, აბზაცები და ტექსტის ფორმატირება

ტექსტის იერარქიისთვის გვაქვს 6 დონის სათაური — <h1>-დან <h6>-მდე (<h1> ყველაზე მნიშვნელოვანია), ჩვეულებრივი ტექსტისთვის — <p>. 

<h1>Front-End Development</h1>
<h2>რატომ ღირს ამის სწავლა</h2>
<p>
  Front-end დეველოპმენტი აერთიანებს დიზაინსა და ლოგიკას — შენ ხედავ
  შედეგს პირდაპირ ბრაუზერში, რასაც წერ.
</p>

მნიშვნელოვანია: სათაურის დონე უნდა შეირჩეს დოკუმენტის ლოგიკური იერარქიით, არა ვიზუალური ზომით — ეს გავლენას ახდენს SEO-სა და screen reader-ების მუშაობაზეც.

ტექსტის ცალკეული ნაწილების გამოსაყოფად კი გვაქვს სემანტიკური და ვიზუალური ტეგები:

  • <strong> — მნიშვნელოვანი ტექსტი (სემანტიკურად); ვიზუალურად გამუქებულია.
  • <b> — უბრალოდ გამუქებული ტექსტი, მნიშვნელობის გარეშე.
  • <em> — ხაზგასმული, აქცენტირებული ტექსტი (სემანტიკურად); ვიზუალურად დახრილია.
  • <i> — უბრალოდ დახრილი ტექსტი (მაგ. ტერმინი უცხო ენაზე).
  • <sub> — ქვედა ინდექსი (მაგ. ქიმიური ფორმულები).
  • <sup> — ზედა ინდექსი (მაგ. ხარისხები, სქოლიოები).
<p>
  ეს არის <strong>ძალიან მნიშვნელოვანი</strong> ინფორმაცია.
  <em>ნამდვილად</em> ღირს დამახსოვრება.
</p>

<p>წყლის ფორმულაა H<sub>2</sub>O, ხოლო აინშტაინის ფორმულა — E = mc<sup>2</sup></p>

4. ბმულები — ტეგი <a>

ბმული იქმნება <a> (anchor) ტეგით. მთავარი ატრიბუტია href (Hypertext REFerence) — ის მიუთითებს, სად წაგვიყვანს ბმულზე დაწკაპუნება. 

<a href="https://developer.mozilla.org">
  MDN-ის ვიზიტი
</a>

Absolute vs Relative URLs

  • Absolute URL — სრული მისამართი, დომენის ჩათვლით. გამოსადეგია გარე საიტებზე მისამართისთვის.
  • Relative URL — მისამართი, რომელიც ეთვლის მიმდინარე ფაილის მდებარეობას. გამოსადეგია ერთი პროექტის შიდა ფაილებზე.
// Absolute
<a href="https://example.com/about.html">About</a>

// Relative — ამავე პროექტში
<a href="lesson3.html">შემდეგი გაკვეთილი</a>

სასარგებლო ატრიბუტები, სურათი ბმულად და mailto

  • target="_blank" — ბმულს ხსნის ახალ ტაბში.
  • rel="noopener" — უსაფრთხოების საუკეთესო პრაქტიკა target="_blank"-თან ერთად.
  • title — ტექსტი, რომელიც გამოჩნდება ველზე გადასროლისას (tooltip).
<a href="https://react.dev"
   target="_blank"
   rel="noopener"
   title="გახსნის React-ის ოფიციალურ საიტს ახალ ტაბში">
  React დოკუმენტაცია
</a>

<!-- სურათი, როგორც ბმული -->
<a href="index.html">
  <img src="logo.png" alt="საიტის ლოგო">
</a>

<!-- mailto: ბმული -->
<a href="mailto:info@front-end-course.ge">
  დაგვიკავშირდი ელფოსტით
</a>

პრაქტიკული დავალებები

  1. შექმენი ახალი HTML ფაილი სწორი ჩონჩხით და <title>-ით „ჩემი პირველი გვერდი".
  2. დაამატე <h1>, ორი <h2> და სამი <p> — ერთ აბზაცში გამოიყენე <strong> და <em>.
  3. დაწერე ერთი წინადადება, სადაც სწორად ჩაშენებ (nest) <em>-ს <p>-ში, ისე რომ ტეგები არ გადაიჯვარედინოს.
  4. დაამატე ერთი Absolute და ერთი Relative ბმული, ასევე ერთი mailto: ბმული.
  5. (რთული) ჩასმენე სურათი, რომელიც ბმულია — დაწკაპუნებისას მთავარ გვერდზე გადაყვანდეს, და ახალ ტაბში გახსნადი გარე ბმული title ატრიბუტით.
