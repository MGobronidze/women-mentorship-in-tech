Pseudo-classes, Transitions, Animations, Variables

დღეს ვისწავლით თუ, როგორ რეაგირებს ელემენტი მომხმარებლის მოქმედებებზე, როგორ ვამოძრავებთ სტილებს გლუვად და როგორ ვწერთ ხელახლა-გამოსაყენებელ მნიშვნელობებს.

1. Pseudo-classes

Pseudo-class ირჩევს ელემენტს მდგომარეობის მიხედვით — მაგ. მაშინ, როცა კურსორი ზემოთაა, ან როცა ის ჯგუფში პირველია. სინტაქსი: selector:pseudo-class. 

a:hover {
  color: #C97A1E; /* ცვლის ფერს, როცა კურსორი ბმულზეა */
}

button:active {
  transform: scale(0.97); /* დაწკაპუნების მომენტში */
}

input:focus {
  border-color: #146B5C; /* როცა input არჩეულია (focused) */
}

li:first-child { font-weight: 700; }
li:last-child  { border-bottom: none; }
li:nth-child(2n) { background: #F4F1E7; } /* ლუწი ელემენტები */

2. Pseudo-elements

Pseudo-element ირჩევს ელემენტის ნაწილს, რომელიც HTML-ში საერთოდ არ არსებობს — ის „ვირტუალურად" იქმნება CSS-ით. სინტაქსი ორმაგი ორწერტილით: selector::pseudo-element. 

p::first-letter {
  font-size: 2em;
  font-weight: 700;
}

.quote::before {
  content: "„"; /* დამატებული შემცველობა, HTML-ის შეცვლის გარეშე */
}
.quote::after {
  content: "“";
}

::before და ::after ყოველთვის საჭიროებენ content თვისებას (თუნდაც ცარიელს, content: "";), წინააღმდეგ შემთხვევაში საერთოდ არ გამოჩნდება.

3. Transitions — გლუვი გადასვლა

transition საშუალებას გვაძლევს, სტილის ცვლილება (მაგ. :hover-ზე) მოხდეს გლუვად, დროში გაწელილად. 

.btn {
  background: #146B5C;
  transition-property: background, transform; /* რომელი თვისებები იცვლება გლუვად */
  transition-duration: 200ms;                 /* რამდენ ხანში */
  transition-delay: 0ms;                      /* რამდენი ხნის დაყოვნებით დაიწყოს */
  transition-timing-function: ease-out;       /* სიჩქარის „ხასიათი" */

  /* ან shorthand: */
  transition: background 200ms ease-out, transform 150ms ease-out;
}
.btn:hover {
  background: #1B8A75;
  transform: translateY(-2px);
}

4. Animations — @keyframes

transition მუშაობს მხოლოდ ორ მდგომარეობას შორის (მაგ. ჩვეულებრივი → hover). როცა გვჭირდება უფრო რთული, მრავალსაფეხურიანი ანიმაცია — ვიყენებთ @keyframes-ს. 

/* ვაღწერთ ანიმაციის საფეხურებს პროცენტულად */
@keyframes fade-in-up {
  from {
    opacity: 0;
    transform: translateY(12px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.card {
  animation-name: fade-in-up;
  animation-duration: 400ms;
  animation-timing-function: ease-out;
  

  /* ან shorthand: */
  animation: fade-in-up 400ms ease-out both;
}

5. CSS Variables (Custom Properties)

CSS ცვლადები საშუალებას გვაძლევს, ერთხელ განვსაზღვროთ მნიშვნელობა და შემდეგ ბევრგან გამოვიყენოთ — ეს ზუსტად ის სისტემაა, რომელსაც ეს საიტიც იყენებს (--mod-html, --bg და ა.შ. style.css-ში). 

:root {
  --accent: #146B5C;      /* გლობალური ცვლადი, ხელმისაწვდომია ყველგან */
  --radius: 12px;
}

.btn {
  background: var(--accent);       /* var() კითხულობს ცვლადის მნიშვნელობას */
  border-radius: var(--radius);
}
.badge {
  color: var(--accent, black);     /* მეორე არგუმენტი — fallback, თუ ცვლადი არ არსებობს */
}

ჩვეულებრივი Sass/Less ცვლადებისგან განსხვავებით, CSS ცვლადები ცოცხალია ბრაუზერში — მათი შეცვლა JavaScript-იდანაც შესაძლებელია რეალურ დროში, გვერდის ხელახლა ჩატვირთვის გარეშე.

6. Autoprefixer — რატომ გვჭირდება

Autoprefixer არის PostCSS-ის პლაგინი (ინსტრუმენტი), რომელიც ავტომატურად ამატებს ვენდორულ პრეფიქსებს (Vendor Prefixes: -webkit-, -moz-, -ms-, -o-) თქვენს CSS კოდში, Can I Use მონაცემთა ბაზაზე დაყრდნობით. მარტივად რომ ვთქვათ: თქვენ წერთ თანამედროვე, სტანდარტულ CSS-ს, ხოლო Autoprefixer ზრუნავს იმაზე, რომ ეს კოდი ყველა ბრაუზერში (ძველშიც და ახალშიც) გამართულად გამოჩნდეს. ზოგიერთ CSS თვისებას სხვადასხვა ბრაუზერში სჭირდება vendor prefix (მაგ. -webkit-, -moz-), განსაკუთრებით ახალ ან ექსპერიმენტულ თვისებებზე: 

/* Autoprefixer-ის გარეშე, ხელით: */
.box {
  -webkit-transform: rotate(5deg);
  -moz-transform: rotate(5deg);
  transform: rotate(5deg);
}

Autoprefixer არის build-tool (ხშირად ინტეგრირებულია PostCSS-თან), რომელიც ავტომატურად ამატებს საჭირო პრეფიქსებს, browserslist კონფიგურაციის მიხედვით — დეველოპერს ხელით აღარ სჭირდება მათი მართვა.

7. ღილაკები (Buttons)

ღილაკი ალბათ ყველაზე კარგი მაგალითია იმისა, თუ როგორ „მუშაობს ერთად" დღეს ნასწავლი ოთხივე თემა: pseudo-classes უზრუნველყოფს რეაქციას მდგომარეობებზე, transition — გლუვ გადასვლას, CSS ცვლადები — ერთიან და მარტივად შესაცვლელ დიზაინის სისტემას, ხოლო Autoprefixer ზრუნავს იმაზე, რომ ეს ყველაფერი სტაბილურად იმუშაოს სხვადასხვა ბრაუზერში. 

:root {
  --btn-bg: #146B5C;
  --btn-bg-hover: #1B8A75;
  --btn-bg-active: #0F4F44;
  --btn-radius: 10px;
  --btn-shadow: 0 4px 14px rgba(20, 107, 92, 0.25);
}

.btn {
  background: var(--btn-bg);
  color: #fff;
  border: none;
  border-radius: var(--btn-radius);
  padding: 12px 22px;
  font-weight: 600;
  cursor: pointer;

  /* გლუვი გადასვლა ყველა state-ს შორის */
  transition: background 180ms ease-out,
              transform 120ms ease-out,
              box-shadow 180ms ease-out;
}

/* :hover — კურსორი ღილაკზეა */
.btn:hover {
  background: var(--btn-bg-hover);
  box-shadow: var(--btn-shadow);
  transform: translateY(-2px);
}

/* :active — დაწკაპუნების მომენტი */
.btn:active {
  background: var(--btn-bg-active);
  transform: translateY(0) scale(0.97);
  box-shadow: none;
}

/* :focus-visible — კლავიატურით ნავიგაციისას (Tab), მნიშვნელოვანია accessibility-სთვის */
.btn:focus-visible {
  outline: 2px solid var(--btn-bg-hover);
  outline-offset: 2px;
}

/* :disabled — გამორთული მდგომარეობა */
.btn:disabled {
  background: #B9B4A6;
  cursor: not-allowed;
  transform: none;
  box-shadow: none;
}

/* დამატებითი დეკორატიული ისარი, HTML-ის შეცვლის გარეშე */
.btn::after {
  content: "→";
  margin-left: 8px;
  display: inline-block;
  transition: transform 180ms ease-out;
}
.btn:hover::after {
  transform: translateX(4px);
}

/* დატვირთვის ანიმაცია — @keyframes, თუ ღილაკს დინამიურად ვამატებთ გვერდზე */
@keyframes btn-pop-in {
  from { opacity: 0; transform: scale(0.9); }
  to   { opacity: 1; transform: scale(1); }
}
.btn {
  animation: btn-pop-in 250ms ease-out both;
}

რამდენიმე მნიშვნელოვანი დეტალი:

  • :hover და :active ერთმანეთისგან განსხვავებულ მდგომარეობებს წარმოადგენს — :hover „მდგრადია" (სანამ კურსორი ზემოთაა), :active კი მხოლოდ დაწკაპუნების წამია.
  • :focus-visible (და არა უბრალო :focus) გამოიყენება იმისთვის, რომ outline მხოლოდ კლავიატურით ნავიგაციისას გამოჩნდეს და არა თაგუნათი დაწკაპუნებისას — ეს ვიზუალურად უფრო სუფთა შედეგს იძლევა accessibility-ის დაკარგვის გარეშე.
  • ყველა ფერი და რადიუსი გატანილია :root-ის ცვლადებში — თუ პროექტს მეორე ღილაკის ვარიანტი (მაგ. წითელი „საშიში" ღილაკი) დასჭირდება, საკმარისია ახალი კლასი სხვა ცვლადის მნიშვნელობებით, კოდის დუბლირების გარეშე.
  • transform: scale() და translateY() გამოიყენება margin-ის ან top-ის ცვლილების მაგივრად, რადგან ისინი GPU-ზე მუშავდება და არ იწვევს გვერდის თავიდან გადაწყობას (reflow) — ანიმაცია გაცილებით გლუვია.

პრაქტიკული დავალებები

  1. დაუმატე ღილაკს :hover და :active სტილები, transition-ის გამოყენებით გლუვი გადასვლისთვის.
  2. გამოიყენე :nth-child() სიის ლუწ ელემენტებზე განსხვავებული ფონის ფერის დასაყენებლად.
  3. დაამატე ::before-ის გამოყენებით დეკორატიული სიმბოლო ციტატის წინ.
  4. დაწერე @keyframes ანიმაცია, რომელიც ელემენტს ატრიალებს ან აქრობს/აჩენს (fade), და მიაბი ელემენტს.
  5. (რთული) განსაზღვრე 3-4 CSS ცვლადი :root-ში (ფერები, radius) და გამოიყენე ისინი მინიმუმ 3 სხვადასხვა სელექტორში — შემდეგ სცადე ცვლადის მნიშვნელობის შეცვლა ერთ ადგილას და დააკვირდი, როგორ იცვლება მთელი გვერდი.
