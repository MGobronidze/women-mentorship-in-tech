CSS სინტაქსი, სელექტორები, Reset, Box Model

HTML-მა მოგვცა სტრუქტურა. ახლა ვიწყებთ CSS მოდულს — ვისწავლით, როგორ ვხატავთ ამ სტრუქტურას და როგორ „ითვლის" ბრაუზერი თითოეული ელემენტის ზომებს.

1. CSS-ის სინტაქსი

CSS წესი შედგება სელექტორისგან (რომელ ელემენტს ვირჩევთ) და ბლოკისგან ფიგურულ ფრჩხილებში, სადაც ჩამწერია ერთი ან მეტი თვისება: მნიშვნელობა; წყვილი. 

selector {
  property: value;
  property: value;
}

/* მაგალითი */
p {
  color: #171F1B;
  font-size: 16px;
}

CSS-ის დაკავშირების 3 გზა

  • გარეგანი (External) — <link> ტეგით <head>-ში. საუკეთესო პრაქტიკა.
  • შიდა (Internal) — <style> ტეგში, <head>-ში.
  • ჩანაწერი (Inline) — პირდაპირ ელემენტის style ატრიბუტში. გამოსაყენებელია იშვიათად.
<!-- External — რეკომენდებული -->
<link rel="stylesheet" href="style.css">

<!-- Inline -->
<p style="color: red;">ტექსტი</p>

HTML-ის მსგავსად, CSS-შიც შესაძლებელია კომენტარების ჩაწერა — ისინი ჩაწერილია /* ... */ შორის და გავლენას არ ახდენენ სტილზე: 

/* ეს არის კომენტარი — გამოსადეგია კოდის ორგანიზებისთვის */
.btn {
  padding: 10px 16px; /* ღილაკის შიდა მანძილები */
}

2. სელექტორების ტიპები

სელექტორი განსაზღვრავს, რომელ ელემენტ(ებ)ს მიესადაგება სტილი:

/* Element — ეხება ყველა <p>-ს */
p { line-height: 1.6; }

/* Class — ეხება class="card" მქონე ყველა ელემენტს */
.card { border-radius: 12px; }

/* ID — ეხება ერთადერთ, უნიკალურ ელემენტს */
#main-nav { position: sticky; }

/* Universal — ეხება ყველა ელემენტს */
* { box-sizing: border-box; }

/* Descendant — ეხება .card-ის შიგნით ჩადგმულ <p>-ებს */
.card p { color: gray; }

Class გამოსადეგია განმეორებადი სტილებისთვის, ID — ერთადერთი, უნიკალური ელემენტისთვის. ჩვეულებრივ სტილიზაციისთვის Class-ს ვირჩევთ, რადგან ის მრავალჯერ გამოსაყენებელია.

3. Browser Reset და Normalize

სხვადასხვა ბრაუზერს აქვს განსხვავებული ნაგულისხმევი სტილები. ამის გამო, დეველოპერები კურსის დასაწყისში წერენ მცირე reset ბლოკს, რომ ყველა ბრაუზერში ერთნაირი საწყისი წერტილი გვქონდეს. 

/* მინიმალური, თანამედროვე reset */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

img {
  max-width: 100%;
  display: block;
}

Reset აქრობს ნაგულისხმევ სტილებს (და ყველაფერს თავიდან ვწერთ), ხოლო Normalize.css ცდილობს ბრაუზერებს შორის თანაბრობის მიღწევას, ნაგულისხმევი, გამოსადეგი სტილების შენარჩუნებით.

4. CSS Box Model

ყოველი HTML ელემენტი ბრაუზერისთვის არის მართკუთხა „ყუთი" (box), რომელიც შედგება ოთხი ფენისგან, შიდადან გარეთ:

  • Content — ტექსტი ან სხვა შემცველობა.
  • Padding — შიდა მანძილი content-სა და ჩარჩოს შორის.
  • Border — ელემენტის ჩარჩო.
  • Margin — გარე მანძილი, სხვა ელემენტებამდე.
.box {
  width: 300px;
  padding: 20px;
  border: 2px solid #146B5C;
  margin: 16px;
}

box-sizing: content-box vs border-box

ნაგულისხმევად (content-box), width/height ეხება მხოლოდ content-ს — padding და border ემატება ჯამურ ზომას. ეს ხშირად დაუგეგმავ განლაგებას იწვევს. ამიტომ თანამედროვე პროექტებში თითქმის ყოველთვის ვიყენებთ border-box-ს, სადაც width უკვე მოიცავს padding-ისა და border-ის ზომას: 

/* border-box — ყუთის ჯამური სიგანე ყოველთვის 300px-ია */
* {
  box-sizing: border-box;
}

.box {
  width: 300px;
  padding: 20px;
  border: 2px solid black;
  /* content-ის ნამდვილი სიგანე გამოითვლება ავტომატურად */
}

პრაქტიკული დავალებები

  1. დაუკავშირე გარეგანი style.css ერთ HTML გვერდს <link> ტეგით.
  2. დაწერე Element, Class და ID სელექტორები ერთსა და იმავე გვერდზე — თითოეული განსხვავებულ ელემენტს ასტილებდეს.
  3. დაამატე მინიმალური reset ბლოკი შენს პროექტში და DevTools-ის Elements ტაბში დააკვირდი, რა შეიცვალა.
  4. შექმენი ყუთი განსაზღვრული width, padding, border და margin-ით.
  5. (რთული) ერთი და იმავე ელემენტისთვის შეადარე ზომა content-box-სა და border-box-ს შორის — გაზომე DevTools-ის Elements → Computed ტაბში.
