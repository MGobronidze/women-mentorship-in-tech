Burger Menu, call/apply/bind, Higher-Order Functions, Hoisting

დავიწყოთ ერთი კლასიკური, პრაქტიკული პროექტით — მობილური ბურგერ-მენიუთი — და შემდეგ ჩავუღრმავდეთ ფუნქციების რამდენიმე მოწინავე კონცეფციას.

1. Burger Menu ფუნქციონალის აწყობა ანიმაციით

მობილურ ნავიგაციაში სტანდარტული პატერნია: ღილაკი (ჰამბურგერის ხატულა) ხსნის/ხურავს მენიუს, ხოლო თავად ხატულა ტრანსფორმირდება X-ად. HTML-ისა და CSS-ის ნაწილი უკვე ამ საიტის style.css-შიცაა (.nav-toggle, .nav-links) — ახლა დავამატოთ ანიმაცია და JS ლოგიკა. 

/* CSS: ხატულის 3 ხაზის ტრანსფორმაცია X-ად, class-ის მიხედვით */
.nav-toggle span {
  width: 22px; height: 2px; background: black;
  transition: transform 200ms ease, opacity 200ms ease;
}
.nav-toggle[data-open="true"] span:nth-child(1) {
  transform: translateY(6px) rotate(45deg);
}
.nav-toggle[data-open="true"] span:nth-child(2) {
  opacity: 0;
}
.nav-toggle[data-open="true"] span:nth-child(3) {
  transform: translateY(-6px) rotate(-45deg);
}
// JS: ერთი toggle ფუნქცია, state-ს ვინახავთ თავად DOM ატრიბუტში
const toggleBtn = document.querySelector(".nav-toggle");
const navLinks = document.querySelector(".nav-links");

toggleBtn.addEventListener("click", () => {
  const isOpen = toggleBtn.getAttribute("data-open") === "true";
  toggleBtn.setAttribute("data-open", String(!isOpen));
  navLinks.setAttribute("data-open", String(!isOpen));
});

ეს პატერნი — data-* ატრიბუტის toggle-ი JS-დან, ვიზუალური ცვლილება კი CSS transition-ით — ზუსტად ის მიდგომაა, რასაც ეს საიტი (script.js-ის setupNav() ფუნქცია) იყენებს.

2. call, apply და bind

ეს სამივე მეთოდი გვაძლევს კონტროლს იმაზე, თუ რას წარმოადგენს this ფუნქციის შესრულებისას — რაც გამოსადეგია, როცა ფუნქცია სესხულობს ან ერთი ობიექტიდან მეორეზე „გადადის". 

const person = { name: "ანა" };

function greet(greeting) {
  console.log(`${greeting}, ${this.name}!`);
}

// call — გამოძახებს ფუნქციას მაშინვე, this-ს და არგუმენტებს ცალ-ცალკე იღებს
greet.call(person, "გამარჯობა");   // "გამარჯობა, ანა!"

// apply — იგივეა, მაგრამ არგუმენტები მასივის სახით
greet.apply(person, ["სალამი"]);   // "სალამი, ანა!"

// bind — არ სვამს მაშინვე, აბრუნებს ახალ ფუნქციას, "მუდმივად" მიბმულ this-ით
const greetAna = greet.bind(person);
greetAna("დილა მშვიდობისა"); // "დილა მშვიდობისა, ანა!" — გამოძახებადია მოგვიანებით

bind ხშირად გამოიყენება event handler-ებში, როცა გვინდა, ფუნქციამ „დაიმახსოვროს" კონკრეტული this, მაშინაც კი, თუ ის მოგვიანებით, სხვა კონტექსტში გამოიძახება.

3. Higher-Order Functions

Higher-Order Function არის ფუნქცია, რომელიც: (ა) იღებს სხვა ფუნქციას არგუმენტად, ან (ბ) აბრუნებს ფუნქციას. უკვე ვნახეთ ბევრი მაგალითი — map, filter, addEventListener ყველა HOF-ია. 

// ფუნქცია, რომელიც ფუნქციას იღებს არგუმენტად
function repeat(n, action) {
  for (let i = 0; i < n; i++) {
    action(i);
  }
}
repeat(3, (i) => console.log(`გამეორება #${i}`));

// ფუნქცია, რომელიც ფუნქციას აბრუნებს (ე.წ. "ფუნქციათა ქარხანა")
function multiplyBy(factor) {
  return function(number) {
    return number * factor;
  };
}
const double = multiplyBy(2);
const triple = multiplyBy(3);
console.log(double(5)); // 10
console.log(triple(5)); // 15

ეს კონცეფცია პირდაპირ უკავშირდება წინა გაკვეთილში ნასწავლ closure-ს — multiplyBy დაბრუნებული ფუნქცია „ახსოვს" factor-ს.

4. Hoisting

Hoisting არის JavaScript-ის მექანიზმი, რომლის დროსაც ცვლადებისა და ფუნქციების გამოცხადებები (არა მინიჭებები!) გადაინაცვლებს scope-ის თავში, კოდის რეალურად შესრულებამდე. 

console.log(greetHoisted()); // ✅ მუშაობს! "გამარჯობა" — Function Declaration hoisted-ია მთლიანად

function greetHoisted() {
  return "გამარჯობა";
}
console.log(x); // undefined (არა Error!) — var ცვლადი hoisted-ია, მაგრამ მინიჭების გარეშე
var x = 5;

console.log(y); // ❌ ReferenceError — let/const არის "temporal dead zone"-ში hoisting-ამდე
let y = 5;

დასკვნა: Function Declaration მთლიანად ჰოისტდება (გამოძახება შესაძლებელია ადრეც). var ჰოისტდება, მაგრამ undefined-ით. let/const ტექნიკურად ჰოისტდება კიდეც, მაგრამ არ არის ხელმისაწვდომი გამოცხადებამდე (ეს პერიოდი ეწოდება Temporal Dead Zone) — ეს კიდევ ერთი მიზეზია, რატომაც let/const უფრო „უსაფრთხოა" var-თან შედარებით.

პრაქტიკული დავალებები

  1. ააწყვე მუშა ბურგერ-მენიუ (HTML+CSS+JS) — მობილურ ეკრანზე ღილაკი ხსნის/ხურავს ნავიგაციას, ხატულა ტრანსფორმირდება X-ად ანიმაციით.
  2. დაწერე ორი ობიექტი და ერთი ფუნქცია, რომელიც იყენებს this-ს — გამოიძახე ის call-ით ორივე ობიექტისთვის.
  3. დაწერე Higher-Order Function, რომელიც იღებს მასივს და ფუნქციას, და აბრუნებს ახალ მასივს ფუნქციის გამოყენებით (თავად დაწერე შენი "map").
  4. დაწერე კოდის მაგალითი, სადაც ცხადად აჩვენებ var და let ჰოისტინგის სხვაობას (console.log-ის ცვლადის გამოცხადებამდე).
  5. (რთული) გამოიყენე bind, რომ შექმნა „წინასწარ მორგებული" ფუნქცია — მაგ. multiplyBy(2)-ის მსგავსი შედეგი, მაგრამ bind-ის საშუალებით (მინიშნება: ჩვეულებრივი ფუნქცია ორი პარამეტრით, ერთი bind-ით "დაფიქსირებული").
