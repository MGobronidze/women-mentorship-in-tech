Bootstrap, Git & GitHub, რესპონსიული დიზაინი

CSS მოდულის ბოლო გაკვეთილი სამ პრაქტიკულ თემას აერთიანებს: მზა CSS ჩარჩოს (Bootstrap), კოდის ვერსიების მართვას (Git) და იმას, თუ როგორ ვხდით საიტს ყველა ეკრანზე გამოსადეგს.

1. Bootstrap — საბაზისო გამოყენება

Bootstrap არის მზა CSS (და JS) ბიბლიოთეკა, რომელიც გვთავაზობს გამზადებულ კომპონენტებს (ღილაკები, ბარათები, ნავიგაცია) და 12-სვეტიან grid სისტემას. სწრაფად მუშავდება, თუმცა ცოტა ამცირებს დიზაინის კონტროლს, საკუთარი CSS-თან შედარებით. 

<!-- CDN-ით დაკავშირება, საკუთარი style.css-ის ზემოთ -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css"
      rel="stylesheet">
<!-- Bootstrap-ის grid სისტემა და მზა კომპონენტები -->
<div class="container">
  <div class="row">
    <div class="col-md-6">პირველი სვეტი</div>
    <div class="col-md-6">მეორე სვეტი</div>
  </div>

  <button class="btn btn-primary">მოქმედება</button>
</div>

col-md-6 ნიშნავს: „medium (≥768px) ეკრანზე დაიკავე 12-დან 6 სვეტი" — ანუ ნახევარი სიგანე. პატარა ეკრანზე კი, ნაგულისხმევად, თითოეული სვეტი მთელ სიგანეს იკავებს.

2. Git — ვერსიების კონტროლის სისტემა

Git აღრიცხავს კოდის ცვლილებების ისტორიას — შესაძლებელია ნებისმიერ მომენტში დაბრუნება წინა ვერსიაზე, ცვლილებების შედარება, და სხვადასხვა დეველოპერების პარალელური მუშაობა. 

# პროექტის ინიციალიზაცია და პირველი commit
git init
git add .
git commit -m "პირველი commit: საწყისი სტრუქტურა"

# ცვლილებების ისტორიის ნახვა
git status
git log --oneline

# ახალი branch-ის შექმნა ფუნქციონალზე სამუშაოდ
git checkout -b feature/navbar

GitHub — დისტანციური რეპოზიტორია

GitHub არის Git-ის საფუძველზე აშენებული პლატფორმა, სადაც პროექტი ინახება ღრუბელში, ხელმისაწვდომია გუნდისთვის და შესაძლებელია პორტფოლიოს სახითაც იქცეს. 

# ლოკალური რეპოზიტორიის დაკავშირება GitHub-თან
git remote add origin https://github.com/username/front-end-course.git
git push -u origin main

3. რესპონსიული დიზაინი და CSS Media Queries

რესპონსიული (responsive) დიზაინი ნიშნავს, რომ ერთი და იგივე HTML/CSS კარგად გამოიყურება ტელეფონზეც, ტაბლეტზეც და დიდ მონიტორზეც. ამის მთავარი ინსტრუმენტია @media query. 

/* საბაზისო სტილი — მობილურისთვის (Mobile-First მიდგომა) */
.grid {
  display: grid;
  grid-template-columns: 1fr; /* ერთი სვეტი მცირე ეკრანზე */
  gap: 16px;
}

/* ტაბლეტი და მეტი (≥768px) */
@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* დესკტოპი (≥1024px) */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

Mobile-First მიდგომა (ჯერ პატარა ეკრანისთვის ვწერთ, შემდეგ min-width-ით ვამატებთ დიდი ეკრანის სტილებს) დღეს ინდუსტრიის სტანდარტია — უფრო სუფთა და ეფექტურია, ვიდრე საწინააღმდეგო (Desktop-First, max-width-ზე დაფუძნებული) მიდგომა.

ასევე მნიშვნელოვანია <head>-ში viewport მეტა-ტეგის არსებობა (რომელსაც უკვე ვიყენებთ ამ კურსის ყველა გვერდზე): 

<meta name="viewport" content="width=device-width, initial-scale=1.0">

პრაქტიკული დავალებები

  1. დაუკავშირე Bootstrap CDN ერთ გვერდს და ააწყვე 2-სვეტიანი განლაგება row/col-md-6-ის გამოყენებით.
  2. დააინსტალირე Git (თუ ჯერ არ გაქვს), შექმენი ლოკალური რეპოზიტორია და გააკეთე პირველი commit.
  3. შექმენი GitHub ანგარიში (თუ ჯერ არ გაქვს) და ატვირთე პროექტი git push-ით.
  4. დაწერე grid, რომელსაც აქვს 1 სვეტი მობილურზე, 2 — ტაბლეტზე, 3 — დესკტოპზე, @media (min-width: ...)-ის გამოყენებით.
  5. (რთული) გახსენი DevTools-ის Device Toolbar (Ctrl/Cmd + Shift + M) და შეამოწმე შენი გვერდის რესპონსიულობა 3 სხვადასხვა ეკრანის ზომაზე — ჩამწერე, რა გატყდა, თუ რამე გატყდა.
