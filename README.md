# Front-End Development კურსი — 24 გაკვეთილი

HTML, CSS და JavaScript-ზე დაფუძნებული Front-End Development კურსი — თეორია, კომენტირებული
კოდის მაგალითები, დამატებითი რესურსები და პრაქტიკული დავალებები, 24 გაკვეთილად დაყოფილი.

## სტრუქტურა

```
front-end-course/
├── index.html          # მთავარი გვერდი — სილაბუსი, პროგრესის ბარი, მოდულების მიმოხილვა
├── style.css            # საერთო დიზაინ-სისტემა
├── script.js             # სილაბუსის რენდერი, ნავიგაცია, პროგრესის თრექინგი
```

**მოდულები:** HTML (1–3) · CSS (4–8) · JavaScript (9–20) · React (21–24)

## პროგრესის თრექინგი

თითოეულ გაკვეთილს აქვს ღილაკი „მონიშნე გაკვეთილი დასრულებულად". მონიშვნა ინახება
ბრაუზერის `localStorage`-ში — მთავარ გვერდზე (`index.html`) ჩანს საერთო პროგრეს-ბარი
(„X/24 დასრულებული"), ხოლო დასრულებულ გაკვეთილებს სილაბუსის ბადეში ✓ ნიშანი მიენიჭებათ.

**გასათვალისწინებელია:** პროგრესი ინახება თითოეული ბრაუზერის/მოწყობილობის დონეზე ცალკე —
სხვა ბრაუზერში ან ინკოგნიტო რეჟიმში გახსნისას პროგრესი თავიდან იწყება. ეს არის სტატიკური
საიტისთვის ბუნებრივი შეზღუდვა (სერვერზე/ანგარიშზე შენახვა მოითხოვდა ბექენდს).

## ლოკალურად გაშვება

დამატებითი ინსტალაციის გარეშეც შეგიძლია უბრალოდ გახსნა `index.html` ბრაუზერში. უკეთესი
გამოცდილებისთვის (რომ ბმულები/გზები ზუსტად ისე იმუშაოს, როგორც სერვერზე) რეკომენდებულია
local server-ის გამოყენება — მაგ. VS Code-ის **Live Server** გაფართოება, ან:

```bash
# Python-ით
python3 -m http.server 8000

# ან Node.js-ით (npx)
npx serve .
```

## GitHub-ზე ატვირთვა

### 1. თუ Git ჯერ არ გაქვს დაინსტალირებული

გადაამოწმე ტერმინალში:

```bash
git --version
```

თუ არ არის დაინსტალირებული, ჩამოტვირთე [git-scm.com](https://git-scm.com/downloads)-დან.

### 2. რეპოზიტორიის შექმნა GitHub-ზე

1. შედი [github.com](https://github.com)-ზე და დააჭირე **New repository**-ს (მწვანე ღილაკი, ან `+` → New repository).
2. Repository name: მაგ. `front-end-course`.
3. **არ** მონიშნო "Add a README file" (რადგან უკვე გაქვს README ლოკალურად — წინააღმდეგ შემთხვევაში, push-ისას კონფლიქტი გამოვა).
4. დააჭირე **Create repository**-ს.

### 3. ლოკალური პროექტის დაკავშირება და ატვირთვა

პროექტის საქაღალდეში (იქ, სადაც `index.html` და დანარჩენი ფაილებია) გაუშვი:

```bash
cd front-end-course

git init
git add .
git commit -m "საწყისი commit: 24-გაკვეთილიანი Front-End კურსი"

git branch -M main
git remote add origin https://github.com/<შენი-username>/front-end-course.git
git push -u origin main
```

`<შენი-username>` შეცვალე საკუთარი GitHub-ის სახელით. `git push`-ის დროს GitHub შესაძლოა
მოგთხოვოს ავტორიზაცია — თუ პაროლი არ მუშაობს, საჭირო იქნება
[Personal Access Token](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)-ის შექმნა და მისი პაროლის ნაცვლად გამოყენება.

### 4. მომავალი ცვლილებების ატვირთვა

ყოველი შემდეგი ცვლილების შემდეგ (მაგ. ახალი lessonX.html-ის დამატება):

```bash
git add .
git commit -m "მოკლე აღწერა, რა შეიცვალა"
git push
```

## საიტის უფასოდ გამოქვეყნება (GitHub Pages)

GitHub-ზე ატვირთვის შემდეგ, საიტის ცოცხლად გამოსაქვეყნებლად (ვებ-მისამართით, ყველასთვის
ხელმისაწვდომი):

1. რეპოზიტორიაში გადადი **Settings** → **Pages**-ზე.
2. **Source**-ში აირჩიე `Deploy from a branch`.
3. **Branch**-ში აირჩიე `main` და საქაღალდე `/ (root)`, დააჭირე **Save**-ს.
4. რამდენიმე წუთში საიტი ხელმისაწვდომი იქნება მისამართზე:
   `https://<შენი-username>.github.io/front-end-course/`
