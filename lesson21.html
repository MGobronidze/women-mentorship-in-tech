React შესავალი: SPA, Vite, Babel, JSX

კურსის ბოლო მოდულში ვაერთიანებთ ყველაფერს, რაც აქამდე ვისწავლეთ — HTML-ის სტრუქტურული აზროვნება, CSS-ის დიზაინი და JavaScript-ის ლოგიკა — ერთ თანამედროვე ბიბლიოთეკაში, React-ში.

1. რა არის React და SPA კონცეფცია

React არის JavaScript ბიბლიოთეკა (Meta-ს მიერ შექმნილი) UI-ის კომპონენტებად აწყობისთვის. მისი მთავარი იდეა: ინტერფეისი აიწყოს პატარა, ხელახლა გამოსაყენებელი „ბლოკებისგან" (კომპონენტები), რომლებიც საკუთარ მდგომარეობას (state) მართავენ.

React ჩვეულებრივ გამოიყენება SPA-ს (Single Page Application) ასაწყობად — აპლიკაცია, სადაც თავდაპირველად ერთი HTML ფაილი იტვირთება, შემდეგ კი JavaScript-ი დინამიურად ცვლის გვერდის შემცველობას, სრული გვერდის ხელახლა ჩატვირთვის გარეშე (განსხვავებით ჩვენ მიერ აქამდე აწყობილი, „მრავალგვერდიანი" საიტისგან, სადაც თითოეული lessonX.html ცალკე ფაილია).

2. React გარემოს შექმნა Vite-ის გამოყენებით

Vite არის თანამედროვე build tool, რომელიც სწრაფად ქმნის და უშვებს React (და სხვა framework-ების) პროექტებს development რეჟიმში: 

# ახალი React + Vite პროექტის შექმნა
npm create vite@latest my-react-app -- --template react

# პროექტში შესვლა და დამოკიდებულებების დაყენება
cd my-react-app
npm install

# development სერვერის გაშვება
npm run dev

ეს ქმნის საწყის პროექტის სტრუქტურას — src/ საქაღალდეს კომპონენტებით, App.jsx-ს, main.jsx-ს (შესვლის წერტილი) და index.html-ს.

რა არის Babel

Babel არის JavaScript-ის „მთარგმნელი" (transpiler) — ის გარდაქმნის ახალ, თანამედროვე სინტაქსს (JSX-ის ჩათვლით, რომელსაც ახლა ვნახავთ) იმ ფორმაში, რომელსაც ყველა ბრაუზერი გაიგებს. Vite-ის კონფიგურაცია ავტომატურად აწესრიგებს Babel-ის (ან მისი ალტერნატივის) გამოძახებას — დეველოპერს ხელით არაფრის კეთება არ სჭირდება.

3. JSX — HTML-ის მსგავსი სინტაქსი JavaScript-ში

JSX (JavaScript XML) საშუალებას გვაძლევს, HTML-ის მსგავსი სინტაქსი პირდაპირ JavaScript ფაილში დავწეროთ: 

// JSX მაგალითი
const element = <h1 className="title">გამარჯობა, React!</h1>;

ეს არ არის ნამდვილი HTML — ბრაუზერი მას პირდაპირ ვერ გაიგებს. Babel „ბრაწავს" (transpile) JSX-ს ჩვეულებრივ JavaScript ფუნქციის გამოძახებად: 

// JSX (რასაც ვწერთ)
const element = <h1 className="title">გამარჯობა, React!</h1>;

// react.createElement (რაშიც JSX ტრანსფორმირდება "კულისებში")
const element = React.createElement(
  "h1",
  { className: "title" },
  "გამარჯობა, React!"
);

createElement ქმნის ჩვეულებრივ JavaScript ობიექტს, რომელსაც React „აღწერილობად" (React element) იყენებს — მისგან ის ცოდნის ამომდინარე, რეალურ DOM-ს ააგებს.

  • JSX-ში class ხდება className (რადგან class JavaScript-ის დაცული სიტყვაა).
  • JavaScript გამოსახულების ჩასმა შესაძლებელია ფიგურული ფრჩხილებით: { }.
  • ყოველ კომპონენტს უნდა ჰქონდეს ერთი „root" ელემენტი (ან <>...</> fragment).

4. ფუნქციური კომპონენტები

დღეს React-ის კომპონენტები თითქმის ყოველთვის იწერება ჩვეულებრივ JavaScript ფუნქციად, რომელიც აბრუნებს JSX-ს: 

function Welcome() {
  const studentName = "ანა";

  return (
    <div className="welcome">
      <h1>გამარჯობა, {studentName}!</h1>    {/* {} ჩასვამს JS ცვლადს JSX-ში */}
      <p>კეთილი იყოს შენი დაბრუნება React-ის სამყაროში.</p>
    </div>
  );
}

export default Welcome;

კომპონენტის სახელი ყოველთვის იწყება დიდი ასოთი (Welcome, არა welcome) — ეს არის React-ის წესი, რომლითაც ის ცნობს, კომპონენტს იყენებ თუ ჩვეულებრივ HTML ტეგს.

5. კომპონენტების მენეჯმენტი და რენდერი

კომპონენტები „ერთვის" ერთმანეთს, ისევე როგორც ჩვეულებრივი HTML ტეგები — ერთი კომპონენტი შეიძლება მეორეს „შიგნით" გამოვიძახოთ: 

// App.jsx
import Welcome from "./Welcome";

function App() {
  return (
    <div className="app">
      <Welcome />                    {/* კომპონენტის გამოძახება, tag-ის სახით */}
      <p>სხვა შემცველობა...</p>
    </div>
  );
}

export default App;
// main.jsx — "root"-ის შექმნა და მთელი აპლიკაციის რენდერი DOM-ში
import { createRoot } from "react-dom/client";
import App from "./App";

const root = createRoot(document.getElementById("root"));
root.render(<App />);

createRoot + render არის ის „ხიდი", სადაც React პირველად ეხება ნამდვილ DOM-ს — ყოველი index.html ფაილში აუცილებელია ერთი ცარიელი <div id="root"></div>, სადაც React-ი მთელ აპლიკაციას „ჩაამონტაჟებს".

პრაქტიკული დავალებები

  1. დააინსტალირე Node.js (თუ ჯერ არ გაქვს) და შექმენი ახალი React პროექტი npm create vite@latest-ის გამოყენებით.
  2. გაუშვი npm run dev და გახსენი პროექტი ბრაუზერში — შეცვალე App.jsx-ში ტექსტი და დააკვირდი, როგორ ცვლილება ავტომატურად ჩანს ბრაუზერში.
  3. შექმენი ახალი ფაილი Greeting.jsx ერთი მარტივი ფუნქციური კომპონენტით და import-ის გამოყენებით ჩასვი ის App.jsx-ში.
  4. დაწერე JSX ელემენტი, რომელშიც ჩასმულია JS ცვლადი ({}-ის გამოყენებით) და JS გამოსახულება (მაგ. {2 + 2}).
  5. (რთული) დაწერე ერთი და იგივე მარტივი კომპონენტი ორივე ფორმით — JSX-ით და React.createElement()-ის პირდაპირი გამოძახებით — შეადარე კოდის წაკითხვადობა.
