Display თვისებები, Background და ტექსტის ფორმატირება

წინა გაკვეთილში ვისწავლეთ, როგორ „ითვლის" ბრაუზერი ელემენტის ზომას. ახლა ვნახოთ, როგორ განლაგდება ეს ყუთები ერთმანეთთან და როგორ ვასტილებთ ფონსა და ტექსტს.

1. display: block / inline / inline-block / none

display თვისება განსაზღვრავს, როგორ „იქცევა" ელემენტი გვერდზე — იკავებს თუ არა მთელ სიგანეს, დგება თუ არა ახალ ხაზზე, აქვს თუ არა width/height.

  • block — იკავებს მთელ ხელმისაწვდომ სიგანეს, ყოველთვის იწყება ახალი ხაზიდან (მაგ. <div>, <p>, <h1>).
  • inline — იკავებს მხოლოდ საჭირო სივრცეს, არ იწყება ახალი ხაზიდან, width/height არ მოქმედებს (მაგ. <span>, <a>).
  • inline-block — „ჰიბრიდი": არ იწყება ახალი ხაზიდან (ისევე როგორც inline), მაგრამ width/height/margin მოქმედებს (ისევე როგორც block).
  • none — ელემენტი სრულად ქრება გვერდიდან, თითქოს საერთოდ არ არსებობდეს.
.block-el    { display: block; }
.inline-el   { display: inline; }
.hybrid-el   { display: inline-block; width: 120px; }
.hidden-el   { display: none; } /* არ ჩანს, საერთოდ არ იკავებს სივრცეს */

2. CSS Background

ფონის დასაყენებლად რამდენიმე თვისება გვაქვს, რომლებიც შესაძლებელია ცალ-ცალკე ან ერთიანი background shorthand-ით ჩავწეროთ: 

.hero {
  background-color: #EAE6D9;
  background-image: url("bg.jpg");
  background-size: cover;        /* ფონის სურათი ფარავს მთელ არეს */
  background-position: center;
  background-repeat: no-repeat;
}

/* ან shorthand ჩანაწერით: */
.card {
  background: #FFFFFF url("texture.png") no-repeat center / cover;
}

3. ტექსტის ფორმატირება: fonts, spacing, alignment

ტიპოგრაფია ერთ-ერთი ყველაზე მნიშვნელოვანი დიზაინის ინსტრუმენტია. ძირითადი თვისებებია:

.article {
  font-family: "Noto Sans Georgian", sans-serif;  /* შრიფტების ჯაჭვი, fallback-ებით */
  font-size: 16px;
  font-weight: 700;          /* სისქე: 400 ჩვეულებრივი, 700 გამუქებული */
  line-height: 1.6;          /* ხაზებს შორის მანძილი — კითხვადობისთვის */
  letter-spacing: 0.02em;    /* ასოებს შორის მანძილი */
  text-align: center;        /* left | right | center | justify */
  text-transform: uppercase; /* ავტომატური დიდი ასოები */
  text-decoration: underline;
}

line-height უნდა იყოს ერთეულის გარეშე რიცხვი (მაგ. 1.6), რადგან ის მაშინ პროპორციულად თვლის font-size-ის მიხედვით — ეს კარგი პრაქტიკაა responsive დიზაინისთვის.

პრაქტიკული დავალებები

  1. შექმენი 3 ელემენტი — ერთი block, ერთი inline, ერთი inline-block — და დააკვირდი, როგორ განსხვავდება მათი განლაგება.
  2. დამალე ერთი ელემენტი display: none-ით და შეამოწმე DevTools-ში, რომ ის საერთოდ აღარ იკავებს სივრცეს.
  3. დაუყენე ერთ სექციას ფონის ფერი და მეორეს — ფონის სურათი cover და center პარამეტრებით.
  4. დაასტილე ერთი აბზაცი: შეცვალე font-size, line-height, letter-spacing და text-align.
  5. (რთული) ააწყვე მარტივი „ბარათი" (card): ჩარჩო, ფონის ფერი, სათაური განსხვავებული ფონტის სისქით და ტექსტი — გამოიყენე ერთდროულად box model, display და ტექსტის თვისებები.
