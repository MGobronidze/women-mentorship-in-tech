შედარება, ლოგიკური ოპერატორები და Coercion

პროგრამირება დიდწილად არის გადაწყვეტილებების მიღება: „თუ ეს მართალია, გააკეთე ეს, თუ არადა — სხვა". ამ გაკვეთილში ვისწავლით, როგორ ვწერთ ამ პირობებს JavaScript-ში.

1. შედარების ოპერატორები

let a = 5, b = "5";

a == b     // true  — ტოლობა ტიპის კონვერტაციით (loose equality)
a === b    // false — ტოლობა ტიპის შემოწმებითაც (strict equality)

a != b     // false — არატოლობა, ტიპის კონვერტაციით
a !== b    // true  — მკაცრი არატოლობა

5 > 3      // true
5 >= 5     // true
3 < 5      // true

საუკეთესო პრაქტიკა: ყოველთვის გამოიყენე === და !== (მკაცრი შედარება) და არა ==/!=. ეს გამორიცხავს JavaScript-ის ავტომატური ტიპის კონვერტაციისგან გამოწვეულ მოულოდნელ ბაგებს.

2. ლოგიკური ოპერატორები

let age = 20;
let hasTicket = true;

age >= 18 && hasTicket   // AND — ორივე პირობა უნდა იყოს true
age < 18 || !hasTicket    // OR — საკმარისია ერთ-ერთი იყოს true
!hasTicket               // NOT — ცვლის true/false-ს საწინააღმდეგოთი

3. if / else — პირობითი კონსტრუქცია

let temperature = 3;

if (temperature > 25) {
  console.log("ცხელა — ჩაიცვი მსუბუქი ტანსაცმელი");
} else if (temperature > 10) {
  console.log("ზომიერია — ჯემპერი საკმარისია");
} else {
  console.log("ცივა — გჭირდება ქურთუკი");
}
// output: "ცივა — გჭირდება ქურთუკი"

4. switch — მრავალვარიანტიანი არჩევანი

როცა ერთ ცვლადს ვადარებთ ბევრ კონკრეტულ მნიშვნელობას, switch ხშირად უფრო წაკითხვადია, ვიდრე გრძელი if/else if ჯაჭვი. break აუცილებელია, თორემ შესრულება „ჩამოვარდება" შემდეგ case-ზეც (fall-through). 

let day = "სამშაბათი";

switch (day) {
  case "ორშაბათი":
    console.log("კვირის დასაწყისი");
    break;
  case "სამშაბათი":
  case "ოთხშაბათი":
    console.log("კვირის შუა ნაწილი");
    break;
  default:
    console.log("სხვა დღე");
}
// output: "კვირის შუა ნაწილი"

5. Ternary ოპერატორი — მოკლე if/else

Ternary საშუალებას გვაძლევს ერთ ხაზზე ჩავწეროთ მარტივი პირობა. ფორმა: პირობა ? თუ_true : თუ_false. 

let age = 20;
const status = age >= 18 ? "სრულწლოვანი" : "არასრულწლოვანი";
console.log(status); // "სრულწლოვანი"

// ხშირად გამოიყენება JSX-ში (React-ში ვნახავთ) პირობითი რენდერისთვის

6. Coercion — ტიპების იძულებითი კონვერტაცია

JavaScript ავტომატურად „აკონვერტირებს" მონაცემის ტიპს, როცა ეს საჭიროა ოპერაციის შესასრულებლად — ამას coercion ეწოდება. სამი ძირითადი ტიპია: 

// String coercion — რიცხვი ტექსტად
"5" + 3        // "53" — + ოპერატორი, თუ ერთ-ერთი მხარე String-ია, აწებავს ტექსტებს
String(123)    // "123" — ცხადი (explicit) კონვერტაცია

// Numeric coercion — ტექსტი რიცხვად
"5" - 3        // 2 — მინუსი, ამრავლება, გაყოფა ყოველთვის რიცხვად აქცევს
Number("42")   // 42 — ცხადი კონვერტაცია
Number("abc")  // NaN — "Not a Number"

// Boolean coercion — ნებისმიერი მნიშვნელობა true/false-ად
Boolean(0)     // false
Boolean("")    // false
Boolean(null)  // false
Boolean("0")   // true  — არა-ცარიელი სტრიქონი ყოველთვის true-ა!
Boolean(1)     // true

მნიშვნელობებს, რომლებიც Boolean()-ში false-ად იქცევა, ეწოდება falsy მნიშვნელობები: 0, "", null, undefined, NaN, false. ყველა დანარჩენი — truthy-ა. სწორედ ამიტომ არის === (მკაცრი შედარება) ასეთი მნიშვნელოვანი — ის თავიდან გვაცილებს coercion-ით გამოწვეულ მოულოდნელობებს.

პრაქტიკული დავალებები

  1. დაწერე if/else if/else კონსტრუქცია, რომელიც შეაფასებს ქულას (0–100) და დაბეჭდავს „ჩავარდა" / „საშუალო" / „კარგი" / „ბრწყინვალე".
  2. იგივე ლოგიკა გადათარგმნე switch-ის გამოყენებით (მაგ. თვის ნომრით სეზონის დასადგენად).
  3. დაწერე ternary გამონათქვამი, რომელიც ერთ ხაზზე ამოწმებს, არის თუ არა რიცხვი ლუწი.
  4. Console-ში გამოსცადე 5 coercion-ის მაგალითი (მაგ. "10" + 5, "10" - 5, Boolean("")) და ჩამწერე მოსალოდნელი და რეალური შედეგები.
  5. (რთული) დაწერე ლოგიკური გამონათქვამი && და ||-ის კომბინაციით, რომელიც ამოწმებს, არის თუ არა მომხმარებელი „სავალდებულო ასაკის და ტიკეტის" პირობის შესაბამისი, და ახსენი, რატომ დააბრუნა JS-მ ზუსტად ის მნიშვნელობა, რაც დააბრუნა (მოძებნე „short-circuit evaluation" ტერმინი).
