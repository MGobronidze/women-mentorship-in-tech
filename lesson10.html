JS სინტაქსი, NPM გარემო, ცვლადები და მონაცემთა ტიპები

აქამდე ვხატავდით სტატიკურ გვერდებს. ახლა ვამატებთ იმ ფენას, რომელიც გვერდს „ცოცხალს" ხდის — JavaScript-ს. დავიწყოთ ენის ბაზისური სინტაქსით და მონაცემების შენახვის ხერხებით.

1. JavaScript-ის სინტაქსი — პირველი ნაბიჯები

JavaScript-ის კოდი შეიძლება ჩავსვათ HTML-ში <script> ტეგით, ან — უკეთესი პრაქტიკაა — ცალკე .js ფაილში, რომელსაც HTML-დან ვუკავშირდებით: 

<script src="script.js"></script>

ბრძანებები (statements) მთავრდება წერტილ-მძიმით (;) — ეს არ არის აბსოლუტურად სავალდებულო (JS-ს აქვს ავტომატური „Automatic Semicolon Insertion"), მაგრამ კარგი პრაქტიკაა მისი ხელით ჩაწერა, გაუთვალისწინებელი შეცდომების თავიდან ასაცილებლად. 

// ერთხაზიანი კომენტარი
console.log("გამარჯობა, JavaScript!"); // გამოაქვს ტექსტი DevTools Console-ში

/* მრავალხაზიანი
   კომენტარი */

2. NPM — JavaScript-ის პაკეტების მენეჯერი

NPM (Node Package Manager) არის ინსტრუმენტი, რომელიც საშუალებას გვაძლევს დავამატოთ ჩვენს პროექტში სხვების მიერ დაწერილი, მრავალჯერ გამოსაცდელი კოდის პაკეტები (მაგ. React, Axios). ის მოდის Node.js-თან ერთად. 

# პროექტის ინიციალიზაცია — ქმნის package.json ფაილს
npm init -y

# პაკეტის დაყენება (მაგ. axios)
npm install axios

# პაკეტის დაყენება მხოლოდ დეველოპმენტისთვის (მაგ. ტესტირების ინსტრუმენტი)
npm install --save-dev vitest

package.json ფაილი აღრიცხავს პროექტის ყველა დამოკიდებულებას (dependency) — სხვას შეუძლია ერთი ბრძანებით (npm install) დააყენოს ისინი ყველა ერთდროულად.

3. ცვლადები: let, const, var

ცვლადი არის „კონტეინერი" მონაცემისთვის. JavaScript-ს აქვს სამი გზა ცვლადის გამოსაცხადებლად: 

let age = 25;        // მნიშვნელობის შეცვლა შესაძლებელია
age = 26;             // ✅ მუშაობს

const name = "ანა";   // მნიშვნელობა უცვლელია, ხელახლა მინიჭება არ შეიძლება
name = "მარი";         // ❌ Error: Assignment to constant variable

var city = "თბილისი"; // ძველი სინტაქსი (ES5-მდე), დღეს იშვიათად გამოიყენება
  • const — ნაგულისხმევი არჩევანი. გამოიყენე, თუ ცვლადს ხელახლა არ მიანიჭებ.
  • let — გამოიყენე, თუ იცი, რომ მნიშვნელობა შეიცვლება (მაგ. მთვლელი ციკლში).
  • var — მოძველებულია; მისი „scope" ქცევა (function-level, არა block-level) ხშირად შეცდომების წყაროა. თანამედროვე კოდში პრაქტიკულად აღარ გამოიყენება.

მნიშვნელოვანია: const კრძალავს ცვლადის ხელახლა მინიჭებას, მაგრამ არა ობიექტის/მასივის შიდა შემცველობის შეცვლას — ამას მომდევნო გაკვეთილებში დავინახავთ.

4. მონაცემთა ტიპები (Data Types)

JavaScript-ს აქვს რამდენიმე საბაზისო (primitive) ტიპი და ორი კომპლექსური (reference) ტიპი:

// Primitive ტიპები
let studentAge = 22;              // Number
let studentName = "გიორგი";       // String
let isEnrolled = true;            // Boolean
let middleName = undefined;      // Undefined — ცვლადს ჯერ არ აქვს მნიშვნელობა
let noValue = null;               // Null — შეგნებულად „ცარიელი" მნიშვნელობა

// Reference ტიპები (მომდევნო გაკვეთილებში ჩავუღრმავდებით)
let hobbies = ["კითხვა", "ცურვა"]; // Object (Array)
let student = { name: "გიორგი" };  // Object

// typeof ოპერატორი ამოწმებს ტიპს
console.log(typeof studentAge);   // "number"
console.log(typeof isEnrolled);   // "boolean"
console.log(typeof hobbies);      // "object" (მასივიც ობიექტია!)

undefined vs null ხშირად აბნევს დამწყებებს: undefined ავტომატურად ენიჭება ცვლადს, რომელსაც ჯერ მნიშვნელობა არ მიუციათ, ხოლო null დეველოპერი შეგნებულად წერს, რომ აღნიშნოს „აქ განზრახ არაფერია".

პრაქტიკული დავალებები

  1. შექმენი script.js ფაილი, დაუკავშირე HTML გვერდს და გამოიყენე console.log() DevTools Console-ში შესამოწმებლად.
  2. გამოაცხადე 5 ცვლადი — თითოეული სხვადასხვა primitive ტიპით (number, string, boolean, undefined, null) — და დაბეჭდე თითოეულის typeof Console-ში.
  3. სცადე const-ით გამოცხადებული ცვლადის ხელახლა მინიჭება და დააკვირდი Console-ში გამოსულ შეცდომას.
  4. დააინსტალირე Node.js (თუ ჯერ არ გაქვს), გაუშვი npm init -y ცარიელ საქაღალდეში და შეისწავლე შედეგად მიღებული package.json.
  5. (რთული) დაწერე პატარა სკრიპტი, რომელიც აცხადებს სტუდენტის ინფორმაციას (სახელი, ასაკი, ჩარიცხულია თუ არა) ცალკეულ ცვლადებში და კონსოლში ბეჭდავს წინადადებას ამ ცვლადების გამოყენებით (template literal-ის — `${}` — გამოყენებით).
