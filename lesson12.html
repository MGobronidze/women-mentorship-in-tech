JS · 12/24 — საკონტროლო შეხვედრა

მასივები, ობიექტები, თანამედროვე მეთოდები, საკონტროლო პროექტი

რეალურ აპლიკაციებში მონაცემები იშვიათად არსებობს ცალკეულ ცვლადებად — ისინი ჯგუფდება მასივებში და ობიექტებში. ვისწავლოთ, როგორ ვინახავთ, ვიღებთ და ვამუშავებთ მათ — და გაკვეთილის ბოლოს, ერთად ავაწყოთ რეალური, პირველი 12 შეხვედრის მასალაზე დაფუძნებული პროექტი.

1. მასივები (Arrays)

მასივი ინახავს დალაგებულ სიას,რომელიც ინდექსით წვდომადია (ინდექსირება იწყება 0-დან). 

const fruits = ["ვაშლი", "მსხალი", "ბანანი"];

console.log(fruits[0]);     // "ვაშლი"
console.log(fruits.length); // 3

fruits[1] = "ატამი";        // ელემენტის შეცვლა ინდექსით
fruits.push("ხურმა");       // დამატება ბოლოში
fruits.pop();                // ბოლო ელემენტის წაშლა

მნიშვნელოვანია: const-ით გამოცხადებული მასივის შემცველობის შეცვლა (push, [i] = ...) დაშვებულია — const მხოლოდ თავად ცვლადის ხელახლა მინიჭებას კრძალავს (fruits = [...] არ იმუშავებდა).

Array.at() — ბოლო ელემენტის მარტივი წვდომა

ძველად ბოლო ელემენტის მისაღებად fruits[fruits.length - 1] გვჭირდებოდა — ცოტა რთული, ადვილად შეცდომის მომტანი. .at() (ES2022, დღეს ყველგან მხარდაჭერილი) იღებს უარყოფით ინდექსსაც, ბოლოდან იწყებს ათვლას: 

const nums = [10, 20, 30, 40];

nums[nums.length - 1]; // 40 — ძველი გზა
nums.at(-1);            // 40 — თანამედროვე, წაკითხვადი გზა
nums.at(-2);             // 30 — ბოლოდან მეორე

2. ობიექტები (Objects)

ობიექტი ინახავს მონაცემებს key: value წყვილებად — გამოსადეგია, როცა მონაცემს აქვს დასახელებული თვისებები (და არა უბრალოდ თანმიმდევრობა). 

const student = {
  name: "გიორგი",
  age: 22,
  isEnrolled: true,
  hobbies: ["კითხვა", "ცურვა"],  // ობიექტს შეიძლება ჰქონდეს მასივიც შიგნით
};

Object.keys() / values() / entries() — ობიექტის „გახსნა"

ეს სამი მეთოდი ობიექტს გარდაქმნის მასივად — რაც საშუალებას გვაძლევს, გამოვიყენოთ მასივის ყველა ის მეთოდი (map, filter და სხვ.), რომელსაც ქვემოთ ვისწავლით: 

Object.keys(student);    // ["name", "age", "isEnrolled", "hobbies"]
Object.values(student);   // ["გიორგი", 22, true, ["კითხვა", "ცურვა"]]
Object.entries(student);  // [["name", "გიორგი"], ["age", 22], ...] — key/value წყვილების მასივი

// პრაქტიკული გამოყენება: for...of + entries() ერთდროულად key-ისა და value-ის მისაღებად
for (const [key, value] of Object.entries(student)) {
  console.log(`${key}: ${value}`);
}

Object.hasOwn() და structuredClone()

// Object.hasOwn() — თანამედროვე, უსაფრთხო გზა შემოწმებისთვის, აქვს თუ არა ობიექტს კონკრეტული key
Object.hasOwn(student, "age");   // true
Object.hasOwn(student, "email"); // false

// structuredClone() — ობიექტის/მასივის სრული, "ღრმა" ასლი (deep copy)
const studentCopy = structuredClone(student);
studentCopy.name = "ანა"; // ორიგინალ student-ს არ ეხება — ეს ნამდვილი, დამოუკიდებელი ასლია

რატომ არის structuredClone() მნიშვნელოვანი: ჩვეულებრივი მინიჭება (const copy = student) მხოლოდ მისამართს აკოპირებს — ორივე ცვლადი ერთსა და იმავე ობიექტს „უყურებს", და ერთის შეცვლა მეორესაც ცვლის. structuredClone() ქმნის სრულიად დამოუკიდებელ, ახალ ასლს — ეს დღეს სტანდარტული, ჩაშენებული გზაა (ძველად ამისთვის გარე ბიბლიოთეკები, მაგ. Lodash, გვჭირდებოდა).

3. Dot vs Bracket Notation

ობიექტის თვისების წაკითხვის ორი გზა არსებობს:

// Dot notation — მარტივი, წაკითხვადი (როცა key წინასწარ ცნობილია)
console.log(student.name);  // "გიორგი"

// Bracket notation — აუცილებელია, როცა key არის ცვლადში ან შეიცავს სპეც. სიმბოლოებს
const key = "age";
console.log(student[key]);       // 22 — dot-ით ეს შეუძლებელია: student.key არასწორია
console.log(student["is enrolled?"]); // bracket საჭიროა space-ის შემცველი key-სთვის

წესი: გამოიყენე dot notation ყოველთვის, როცა key-ს წინასწარ იცნობ და ის სწორი იდენტიფიკატორია; bracket — მხოლოდ მაშინ, როცა key დინამიურია (ცვლადშია) ან შეიცავს space-ს/სპეც. სიმბოლოებს.

4. ციკლები მასივებზე და ობიექტებზე

წინა გაკვეთილში საფუძვლიანად ვისწავლეთ for და while — აქ ვნახოთ, კონკრეტულად როგორ გამოვიყენოთ ისინი (და ორი მათი „ნათესავი") მასივებსა და ობიექტებზე: 

// for...of — მასივის ელემენტებზე გადასვლისთვის (მარტივი, თანამედროვე)
for (const fruit of fruits) {
  console.log(fruit);
}

// for...in — ობიექტის key-ებზე გადასვლისთვის
for (const key in student) {
  console.log(key, "=", student[key]); // bracket აუცილებელია, key ცვლადშია
}

დღეს, მასივებზე გადასასვლელად, ხშირად for...of-ს ან მასივის მეთოდებს ვამჯობინებთ კლასიკურ for-ს — უფრო წაკითხვადია და ნაკლებ შეცდომას იძლევა (მაგ. „off-by-one").

5. მასივის მეთოდები

JavaScript-ის მასივებს აქვთ ჩაშენებული მეთოდები, რომლებიც ცვლიან, ფილტრავენ ან გარდაქმნიან მასივს ციკლის ხელით დაწერის გარეშე: 

const numbers = [1, 2, 3, 4, 5];

// map — ქმნის ახალ მასივს, თითოეულ ელემენტზე ფუნქციის გამოყენებით
const doubled = numbers.map(n => n * 2);      // [2, 4, 6, 8, 10]

// filter — ქმნის ახალ მასივს, მხოლოდ პირობის დამაკმაყოფილებელი ელემენტებით
const evens = numbers.filter(n => n % 2 === 0); // [2, 4]

// forEach — უბრალოდ იმეორებს, ახალ მასივს არ აბრუნებს
numbers.forEach(n => console.log(n));

// find — აბრუნებს პირველ ელემენტს, რომელიც პირობას აკმაყოფილებს
const firstEven = numbers.find(n => n % 2 === 0); // 2

// reduce — ს დაჰყავს მასივს ერთ მნიშვნელობაზე (მაგ. ჯამი)
const sum = numbers.reduce((total, n) => total + n, 0); // 15

Immutable მეთოდები — toSorted, toReversed, toSpliced, with (ES2023)

კლასიკური sort(), reverse() და splice() ცვლიან ორიგინალ მასივს ადგილზევე (mutate) — ეს ხშირად მოულოდნელი bug-ების წყაროა, განსაკუთრებით მაშინ, როცა იმავე მასივს სხვაგანაც იყენებ. 2023 წლიდან, დღეს ყველა თანამედროვე ბრაუზერში მხარდაჭერილი, არსებობს „უსაფრთხო", immutable ალტერნატივები — ისინი აბრუნებენ ახალ მასივს, ორიგინალს კი ხელუხლებელს ტოვებენ: 

const original = [3, 1, 4, 1, 5];

// ძველი, mutating მეთოდი — პირდაპირ ცვლის original-ს!
original.sort(); // original ახლა არის [1, 1, 3, 4, 5] — შეუქცევადად შეიცვალა

const original2 = [3, 1, 4, 1, 5];
// ახალი, "უსაფრთხო" მეთოდი — ორიგინალს არ ეხება
const sorted = original2.toSorted();    // [1, 1, 3, 4, 5] — ახალი მასივი
console.log(original2);                       // [3, 1, 4, 1, 5] — უცვლელია!

const reversed = original2.toReversed(); // ახალი, შებრუნებული ასლი
const updated = original2.with(0, 99);    // ახალი ასლი, სადაც ინდექს 0-ს აქვს 99

Object.groupBy() — ჯგუფური დაჯგუფება (ES2024)

ხშირი ამოცანაა მასივის ელემენტების კატეგორიების მიხედვით დაჯგუფება. ES2024-მდე ეს reduce()-ით იწერებოდა (რამდენიმე ხაზად) — Object.groupBy() ამას ერთ ხაზამდე ამცირებს: 

const products = [
  { name: "წიგნი", category: "განათლება" },
  { name: "რვეული", category: "განათლება" },
  { name: "ყურსასმენი", category: "ტექნიკა" },
];

const grouped = Object.groupBy(products, (p) => p.category);
// {
//   განათლება: [{name: "წიგნი", ...}, {name: "რვეული", ...}],
//   ტექნიკა: [{name: "ყურსასმენი", ...}]
// }

6. საკონტროლო პროექტი — 1-12 შეხვედრების მასალის გამოყენებით

დროა, ყველაფერი ერთად გამოვსცადოთ. ეს პროექტი შეგნებულად იყენებს მხოლოდ იმას, რაც უკვე ვისწავლეთ (HTML/CSS მოდულები სრულად, JS — სინტაქსი, ცვლადები, პირობები, ციკლები, მასივები/ობიექტები) — ჯერ არ ვიყენებთ DOM მანიპულაციას (მე-15 გაკვეთილი), event-ებს (მე-16) ან საკუთარ ფუნქციებს (მე-13). გავარკვიოთ, რამდენის აწყობა შეგვიძლია მხოლოდ ამ ცოდნით, სანამ შემდეგ საფეხურზე გადავალთ.

დავალება: „მინი პორტფოლიოს გვერდი + მონაცემთა ფენა"

პროექტი შედგება ორი ნაწილისგან:

  • ნაწილი A — HTML/CSS: სრული, სტატიკური პორტფოლიოს გვერდი (1-8 გაკვეთილების ცოდნა).
  • ნაწილი B — JS მონაცემთა ფენა: პროექტების მასივი ობიექტების სახით, დამუშავებული Console-ში (9-12 გაკვეთილების ცოდნა).

ნაწილი A — HTML/CSS მოთხოვნები (checklist)

  • <header> — sticky ნავიგაცია, Flexbox-ით (justify-content: space-between)
  • <main> — მინიმუმ 3 <section>: შესახებ, პროექტები, კონტაქტი
  • პროექტების სექცია — CSS Grid-ით, repeat(auto-fit, minmax(240px, 1fr))
  • უნარების სია — <ul>, სემანტიკურად სწორად
  • კონტაქტის ფორმა — <form>, <label>/<input> წყვილები, ვალიდაცია (required, type="email")
  • რესპონსიული — Mobile-First, @media query მინიმუმ ერთი breakpoint-ისთვის
  • <footer> — საკონტაქტო ინფორმაცია
  • ტიპოგრაფია — Google Fonts ან web-fonts.ge, rem-ის გამოყენებით

ნაწილი B — JS მონაცემთა ფენა

ცალკე data.js ფაილში, ააწყვე შენი პროექტების „მონაცემთა ბაზა" და დაამუშავე ის უკვე ნასწავლი ხერხებით — ჯერჯერობით მხოლოდ Console-ში, გვერდზე რენდერს (document.createElement) მე-15 გაკვეთილში ვისწავლით: 

const projects = [
  { title: "To-Do აპლიკაცია", year: 2025, tags: ["JS", "CSS"], featured: true },
  { title: "პორტფოლიოს საიტი", year: 2026, tags: ["HTML", "CSS"], featured: true },
  { title: "ამინდის ვიჯეტი", year: 2025, tags: ["JS", "API"], featured: false },
  { title: "ბლოგის დიზაინი", year: 2024, tags: ["CSS", "Figma"], featured: false },
];

// 1. filter — მხოლოდ გამორჩეული (featured) პროექტები
const featuredProjects = projects.filter(p => p.featured);

// 2. map — თითოეული პროექტისთვის ფორმატირებული სტრიქონის შექმნა
const summaries = projects.map(p => `${p.title} (${p.year})`);

// 3. reduce — რამდენი განსხვავებული tag გამოიყენება სულ (რაოდენობა)
const tagCount = projects.reduce((total, p) => total + p.tags.length, 0);

// 4. Object.groupBy — პროექტების დაჯგუფება წლის მიხედვით
const byYear = Object.groupBy(projects, (p) => p.year);

// 5. for...of + Object.entries — ყველაფრის ორგანიზებულად დაბეჭდვა Console-ში
for (const project of projects) {
  const tagList = project.tags.join(", ");
  const status = project.featured ? "⭐ გამორჩეული" : "ჩვეულებრივი";
  console.log(`${project.title} — ${project.year} — [${tagList}] — ${status}`);
}

console.log("გამორჩეული პროექტები:", featuredProjects.length);
console.log("წლების მიხედვით დაჯგუფებული:", byYear);

  1. შექმენი მასივი 5 ქალაქის სახელით და for...of-ის გამოყენებით დაბეჭდე თითოეული Console-ში.
  2. შექმენი ობიექტი, რომელიც აღწერს წიგნს (title, author, year, isAvailable) — წაიკითხე ორივე notation-ით (dot და bracket).

  4. შექმენი მასივი რიცხვებით და filter()-ის გამოყენებით გამოყავი მხოლოდ 10-ზე მეტი რიცხვები.
  5. იგივე მასივზე გამოიყენე map(), რომ ყველა რიცხვი 3-ჯერ გაზარდო, და reduce(), რომ დაითვალო ჯამი.
  6. შექმენი მასივი, გამოსცადე toSorted() და sort() ორივე — დაბეჭდე ორიგინალი მასივი ორივეს შემდეგ და შეადარე განსხვავება.
  7. შექმენი მასივი 6+ „პროდუქტის" ობიექტით (name, category) და Object.groupBy()-ის გამოყენებით დააჯგუფე კატეგორიების მიხედვით.
  8. (რთული) შექმენი მასივი 5 „სტუდენტის" ობიექტით (თითოეულს აქვს name და grade), filter()-ის გამოყენებით გამოყავი მხოლოდ ისინი, ვისი grade-იც 90-ზე მეტია, შემდეგ map()-ის გამოყენებით შექმენი ახალი მასივი მხოლოდ სახელებით.
