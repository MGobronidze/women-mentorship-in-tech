მასივები, ობიექტები, Dot vs Bracket, ციკლები

რეალურ აპლიკაციებში მონაცემები იშვიათად არსებობს ცალკეულ ცვლადებად — ისინი ჯგუფდება მასივებში და ობიექტებში. ვისწავლოთ, როგორ ვინახავთ, ვიღებთ და ვიმეორებთ მათზე მოქმედებებს.

1. მასივები (Arrays)

მასივი ინახავს დალაგებულ სიას, ინდექსით წვდომადს (ინდექსი იწყება 0-დან). 

const fruits = ["ვაშლი", "მსხალი", "ბანანი"];

console.log(fruits[0]);     // "ვაშლი"
console.log(fruits.length); // 3

fruits[1] = "ატამი";        // ელემენტის შეცვლა ინდექსით
fruits.push("ხურმა");       // დამატება ბოლოში
fruits.pop();                // ბოლო ელემენტის წაშლა

მნიშვნელოვანია: const-ით გამოცხადებული მასივის შემცველობის შეცვლა (push, [i] = ...) დაშვებულია — const მხოლოდ თავად ცვლადის ხელახლა მინიჭებას კრძალავს (fruits = [...] არ იმუშავებდა).

2. ობიექტები (Objects)

ობიექტი ინახავს მონაცემებს key: value წყვილებად — გამოსადეგია, როცა მონაცემს აქვს დასახელებული თვისებები (და არა უბრალოდ თანმიმდევრობა). 

const student = {
  name: "გიორგი",
  age: 22,
  isEnrolled: true,
  hobbies: ["კითხვა", "ცურვა"],  // ობიექტს შეიძლება ჰქონდეს მასივიც შიგნით
};

3. Dot vs Bracket Notation

ობიექტის თვისების წაკითხვის ორი გზა არსებობს:

// Dot notation — მარტივი, წაკითხვადი (როცა key წინასწარ ცნობილია)
console.log(student.name);  // "გიორგი"

// Bracket notation — აუცილებელია, როცა key არის ცვლადში ან შეიცავს სპეც. სიმბოლოებს
const key = "age";
console.log(student[key]);       // 22 — dot-ით ეს შეუძლებელია: student.key არასწორია
console.log(student["is enrolled?"]); // bracket საჭიროა space-ის შემცველი key-სთვის

წესი: გამოიყენე dot notation ყოველთვის, როცა key-ს წინასწარ იცნობ და ის სწორი იდენტიფიკატორია; bracket — მხოლოდ მაშინ, როცა key დინამიურია (ცვლადშია) ან შეიცავს space-ს/სპეც. სიმბოლოებს.

4. ციკლები (Loops)

// for — კლასიკური, სრული კონტროლით
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

// for...of — მასივის ელემენტებზე გადასვლისთვის (მარტივი, თანამედროვე)
for (const fruit of fruits) {
  console.log(fruit);
}

// for...in — ობიექტის key-ებზე გადასვლისთვის
for (const key in student) {
  console.log(key, "=", student[key]); // bracket აუცილებელია, key ცვლადშია
}

// while — მუშაობს, სანამ პირობა ჭეშმარიტია
let countdown = 3;
while (countdown > 0) {
  console.log(countdown);
  countdown--;
}

დღეს, მასივებზე გადასასვლელად, ხშირად for...of-ს ან მასივის მეთოდებს ვამჯობინებთ კლასიკურ for-ს — უფრო წაკითხვადია და ნაკლებ შეცდომას იძლევა (მაგ. „off-by-one").

5. მასივის მეთოდები

JavaScript-ის მასივებს აქვთ ჩაშენებული მეთოდები, რომლებიც ცვლიან, ფილტრავენ ან გარდაქმნიან მასივს ციკლის ხელით დაწერის გარეშე: 

const numbers = [1, 2, 3, 4, 5];

// map — ქმნის ახალ მასივს, თითოეულ ელემენტზე ფუნქციის გამოყენებით
const doubled = numbers.map(n => n * 2);      // [2, 4, 6, 8, 10]

// filter — ქმნის ახალ მასივს, მხოლოდ პირობის დამაკმაყოფილებელი ელემენტებით
const evens = numbers.filter(n => n % 2 === 0); // [2, 4]

// forEach — უბრალოდ იმეორებს, ახალ მასივს არ აბრუნებს
numbers.forEach(n => console.log(n));

// find — აბრუნებს პირველ ელემენტს, რომელიც პირობას აკმაყოფილებს
const firstEven = numbers.find(n => n % 2 === 0); // 2

// reduce — "აკეცავს" მასივს ერთ მნიშვნელობამდე (მაგ. ჯამი)
const sum = numbers.reduce((total, n) => total + n, 0); // 15
