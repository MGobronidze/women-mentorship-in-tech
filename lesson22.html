React State/Props, List & Keys, Hooks

წინა გაკვეთილში კომპონენტები „სტატიკური" იყო. ახლა ვასწავლით მათ, დაიმახსოვრონ მონაცემები და შეიცვალონ დროთა განმავლობაში — ეს არის React-ის ნამდვილი ძალა.

1. Props — მონაცემები „მშობლიდან შვილზე"

Props (properties) არის ის გზა, რომლითაც მშობელი კომპონენტი მონაცემებს გადასცემს შვილ კომპონენტს — ისევე, როგორც HTML ატრიბუტს ვწერთ: 

// Card.jsx — იღებს props-ს, როგორც პარამეტრს (ჩვეულებრივ, destructuring-ით)
function Card({ title, price }) {
  return (
    <div className="card">
      <h3>{title}</h3>
      <p>{price}₾</p>
    </div>
  );
}

// App.jsx — props-ის გადაცემა, ატრიბუტების მსგავსად
<Card title="React წიგნი" price={35} />

props არის read-only — შვილ კომპონენტს არასდროს არ შეუძლია საკუთარი props-ის უშუალო შეცვლა. ეს არის React-ის ერთ-ერთი ფუნდამენტური წესი (ცალმხრივი მონაცემთა ნაკადი — one-way data flow).

2. State — useState Hook

State არის მონაცემი, რომელსაც კომპონენტი თავად ფლობს და თავად ცვლის დროთა განმავლობაში (მაგ. მომხმარებლის მოქმედების პასუხად). useState არის React-ის Hook, რომელიც კომპონენტს state-ის დამატების საშუალებას აძლევს: 

import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0); // [მიმდინარე მნიშვნელობა, განახლების ფუნქცია]

  return (
    <div>
      <p>დაწკაპუნებულია: {count} ჯერ</p>
      <button onClick={() => setCount(count + 1)}>
        დაწკაპუნება
      </button>
    </div>
  );
}

მნიშვნელოვანი წესი: state არასდროს არ იცვლება პირდაპირ (count = count + 1 ❌) — ყოველთვის setCount-ის მსგავსი „setter" ფუნქციით. სწორედ ეს გამოძახება ეუბნება React-ს, ხელახლა გამოსახოს (re-render) კომპონენტი ახალი მონაცემით.

3. List & Keys

მასივის რენდერისთვის ვიყენებთ map()-ს (მე-12 გაკვეთილიდან უკვე ნაცნობი) — JSX-ში პირდაპირ ჩასმით: 

const products = [
  { id: 1, name: "წიგნი" },
  { id: 2, name: "ყურსასმენი" },
];

function ProductList() {
  return (
    <ul>
      {products.map(product => (
        <li key={product.id}>{product.name}</li>
      ))}
    </ul>
  );
}

key ატრიბუტი აუცილებელია — ეს არის უნიკალური იდენტიფიკატორი, რომლითაც React ცნობს, რომელი ელემენტი შეიცვალა, დაემატა თუ წაიშალა სიაში. საუკეთესოა გამოვიყენოთ მონაცემის უნიკალური ID (არა მასივის index, თუ სია დინამიურად იცვლება).

4. useEffect Hook

useEffect გამოსადეგია „გვერდითი ეფექტებისთვის" (side effects) — მოქმედებები, რომლებიც კომპონენტის რენდერის მიღმა ხდება: API მოთხოვნები, ტაიმერები, event listener-ები. 

import { useState, useEffect } from "react";

function UserProfile({ userId }) {
  const [user, setUser] = useState(null);

  useEffect(() => {
    // ეს კოდი სრულდება კომპონენტის რენდერის შემდეგ
    fetch(`/api/users/${userId}`)
      .then(res => res.json())
      .then(data => setUser(data));
  }, [userId]); // dependency მასივი — ეფექტი ხელახლა სრულდება, თუ userId შეიცვალა

  if (!user) return <p>იტვირთება...</p>;
  return <h2>{user.name}</h2>;
}

Lifecycle კონცეფცია Hooks-ის კონტექსტში: ძველ, class-კომპონენტებში არსებობდა ცალკეული მეთოდები (componentDidMount, componentDidUpdate) „ცხოვრების ციკლის" სხვადასხვა მომენტისთვის. useEffect ერთ Hook-ში აერთიანებს ამ ყველა შემთხვევას — dependency მასივის მეშვეობით:

  • useEffect(fn, []) — სრულდება მხოლოდ ერთხელ, კომპონენტის პირველი გამოსახვისას (mount).
  • useEffect(fn, [dep]) — სრულდება პირველად, და შემდეგ ყოველთვის, როცა dep იცვლება.
  • useEffect(fn) (მასივის გარეშე) — სრულდება ყოველი რენდერის შემდეგ (იშვიათად გამოსადეგია).

5. useRef Hook

useRef ქმნის „კონტეინერს", რომლის მნიშვნელობის შეცვლა არ იწვევს ხელახალ რენდერს (განსხვავებით useState-ისგან). ორი ძირითადი გამოყენებაა: 

import { useRef, useEffect } from "react";

function SearchInput() {
  const inputRef = useRef(null); // 1. პირდაპირი წვდომა DOM ელემენტზე

  useEffect(() => {
    inputRef.current.focus(); // კომპონენტის ჩატვირთვისას, input ავტომატურად ფოკუსირდება
  }, []);

  return <input ref={inputRef} type="text" />;
}
// 2. მნიშვნელობის შენახვა რენდერებს შორის, ხელახალი რენდერის გამოწვევის გარეშე
function Timer() {
  const renderCount = useRef(0);
  renderCount.current++; // იზრდება, მაგრამ არ იწვევს ხელახალ რენდერს
  return <p>ეს კომპონენტი გამოისახა {renderCount.current} ჯერ</p>;
}
